# SoftwareJutsu Skills

- Keep each skill self-contained at `skills/<skill-name>/SKILL.md`.
- Use lowercase, hyphenated names under 64 characters.
- Write concise, trigger-focused descriptions; do not add generic background material.
- Keep `SKILL.md` under 500 lines. Put detailed, optional material in `references/`.
- Run the skill validator for every added or changed skill.
- Update the Available skills table in the root README when adding a skill.
